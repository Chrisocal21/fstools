# Image Credits

None of these are Farming Simulator / GIANTS Software assets. GIANTS' press kit
(press.giants-software.com) publishes no usage terms, and there's no public
fan-content policy covering third-party tools, so actual game screenshots or map
images stay out of this project — using them would be a real legal gray area, not
just excess caution.

Instead, `public/images/` holds real aerial farmland photography, all under the
[Unsplash License](https://unsplash.com/license) (free for commercial use, no
attribution required — credited here anyway as good practice).
